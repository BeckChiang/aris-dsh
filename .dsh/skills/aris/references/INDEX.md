# ARIS 技能索引

上游：<https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep>（tarball 版本 f76ec8d）。
本目录是原仓库 `skills/` 的逐字镜像（仅做 DSH 路径改写），共 197 个 SKILL.md。

## 怎么用

- 先读 `../SKILL.md`（`aris` 入口技能）确认工作流与门禁。
- 下表 `描述` 列直接来自各技能 frontmatter，用于挑选；正文在 `path` 指向的文件。
- 同名的 A/B/C 三族是同一技能的三种审查后端实现，默认用 A。
